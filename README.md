Original zero-dependency HTML5 Canvas cooking rush game built for [make.fun](https://make.fun/bounty/best-cooking-game-20261125-0137) ("Make the best cooking game", $250 USDC prize pool).

## Gameplay & Features
- **Tactical Bistro Kitchen:** 6 cold larder ingredients (`Tomato`, `Mushroom`, `Prime Steak`, `Salmon Fillet`, `Saffron Rice`, `Brioche Bun`), 2 chopping prep boards, 2 copper sear skillets with a **Gold Perfect Sear** timing window, a simmering saffron broth pot, 2 modular assembly plates, compost bin, and a brass service bell pass.
- **5 Original Multi-Route Dishes:** *Bistro Smash Burger*, *Truffle Char Steak*, *Saffron Mushroom Risotto*, *Saffron Salmon Bowl*, and *Chef Surf & Turf*.
- **Dual Input + Procedural Web Audio:** Play seamlessly with keyboard (`WASD`/Arrows + `Space`/`E` + `Shift`/`Q` Dash + `P` Pause) or mouse click-to-station routing, with zero external assets or network requests.

## Local Play & Build

```sh
node serve.ts
# Open http://127.0.0.1:8080
```

Package submission output:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
